# AI Enhancer 4K Hub 🚀

A lightweight, high-performance web application designed to upscale, sharpen, and crisp images and videos up to **4K Ultra HD** resolution directly in the browser. 

Built using pure client-side JavaScript, Tailwind CSS, and HTML5 Canvas APIs, ensuring **100% data privacy** as files never touch an external server.

---

## ✨ Key Features

- **Multi-Pass Upscaling:** Intelligently scales media up to 1080p or 4K Ultra HD in step increments to preserve structural detail.
- **Custom 3x3 Sharpen Kernel:** Employs an unsharp masking matrix with auto-contrast LUT and luma-based saturation adjustments.
- **Video Stream Processing:** Uses `MediaRecorder` and `requestAnimationFrame` to apply real-time frame-by-frame enhancement.
- **Side-by-Side Comparison:** Interactive split-screen visual comparison slider to inspect before-and-after results.
- **100% Private & Offline:** All matrix computations execute locally inside the browser.
- **Dark/Light Mode Theme:** Fully responsive, modern glassmorphism interface styled with Tailwind CSS.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling:** Tailwind CSS (via CDN), Google Fonts (Sora)
- **Processing Engine:** HTML5 Canvas 2D API, Web Audio API, MediaRecorder API
- **Deployment:** Vercel / GitHub Pages (Static Hosting)
